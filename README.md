# ПОЯСНИТЕЛЬНАЯ ЗАПИСКА

Проект обучения нейронной сети для расчета калорийности блюда по фото

Анализ исходных данных показал, что о каждом блюде доступна следующая информация:

- фото
- масса
- общая калорийность
- состав

* метка для разеделения выборки на обучающую и тестовую

Всего ингредиентов, составляющих блюда 555 по файлу ingredients.csc
При этом используются для описания состава блюд только 200.

В связи с этим пришлось составить словарь ингредиентов и использовать только 200 вместо 555.

В итоге в качестве данных использовал только информацию о составе и изображения

- data/images
- data/dish.csv

В качестве нейросети для распознавания по фото я использовал модель efficientnet_b3, заменил в ней последний слой на классификатор ингредиентов.

В качестве аугментации изображений использовал отражение по горизонтали, отражение по вертикали и поворот.
Возможно, в дальнейшем следует добавить перспективные искажения и работу с цветом, так как при выполнении фото на смартфон примерно эти искажения присутствуют.
Я посмотрел фотки блюд. Их выполняли в кафе (в помещении), поэтому на них есть соответствующие артефакты - тени оконных рам, отсветы искусственных светильников.
В общем можно еще добавить случайных артефактов, но вот как с тенями быть - непонятно. Хотя это реальные условия, в которых приложение должно работать.

Для нормализации данных, определял mean и std по обучающим данным. Потом эти параметры использовал для оценки на валидационных и тестовых данных.

Так как выполнялась нормализация данных, то в модели не содержатся слои нормализации.

Выборку данных из категории train разделил на обучающие и валидационные данные в соотношении 80 / 20

Обучение выполнял в течение 100 эпох. Размер батча выбрал равным 32.

В качестве оптимизатора выбрал AdamW. Использовал регуляризацию (weight_decay), lr задавал разный для моделей.

По результатам обучения в течение 100 эпох, ошибка MAE на обучающих и валидационных данных снизилась <50, а на тестовых данных составила 67.759.
